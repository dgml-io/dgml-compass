Model Compass field guide

The models/ folder holds the Model Compass experiment pipeline. It runs dgml over the reference corpus with different models in the transcribe and label slots, scores the DGML that comes out, and packages the evidence for model-compass-proto, which fits the registry tiers. It replaces model-compass-automation and reproduces its numbers.

Distribution
dgml-model-compass
Import
model_compass
Command
uv run dgc
Python
3.12 · uv project

One experiment is a spec (YAML). A spec crosses its axes (for example the label model) with the selected docsets; each combination is a cell, and each cell is repeated as draws. A draw is one dgml generation over a small document sample, and everything downstream is measured per cell, docset and draw.

Run directory

  
Every dgc run writes one directory under runs_dir, named YYYYMMDD-HHMMSS-<hash>. The layout is the same as the source's, so runs made by model-compass-automation load unchanged. Select a file to see what it holds.

  

    

    

  






  
Metric families

  
One record per (cell, docset, draw, family) in metrics/<cell_id>.jsonl. Absent is not zero: a metric that cannot be computed is listed in absent and has no value. Scales differ by family.

API keys

  
dgml reads the keys itself; dgc only loads .env so dgml inherits it. You need keys only for the providers a spec uses: ANTHROPIC_API_KEY for anthropic/claude-*, GEMINI_API_KEY for gemini/gemini-*, OPENAI_API_KEY for openai/gpt-*. A missing key or empty credit makes those draws come back with no DGML; fix the key and run dgc run --resume <run_id> --retry-empty --yes.

Tests & parity

  
Parity with the source is the gate. Goldens are produced by running the source code read-only on copies of real runs (scripts/make_golden_*.py), and the tests compare against them.

  

    
What is held equal
    
      
  • Scoring records on 4 real draws, to 1e-9
    • 
      
  • compass_grid.csv byte-identical, plus the appended role-price columns
    • 
      
  • Handoff pack byte-identical
    • 
      
  • Planner output (cells, draws, prices) for all kept specs
    • 
      
  • All 36 source runs parse
    • 
    

    
Running them

      
uv run pytest            # `corpus` tests skip without ../dgml_reference_data
uv run ruff format . && uv run ruff check .

      
A change that moves a number must say why in docs/DECISIONS.md and regenerate the goldens.
